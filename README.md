## 在另一台电脑上继续开发

1. 安装 [RPG Maker MZ](https://store.steampowered.com/app/1096900/RPG_Maker_MZ/)（Steam）
2. `git clone` 本仓库
3. 用 MZ 打开 `工程/Game.rmmzproject` 即可（NW.js 运行时由 MZ 提供，已从仓库排除；正式发布用编辑器"部署"功能生成完整包）

## 开发铁律（违反必翻车）

- **改 `工程/data/*.json` 前必须关闭 MZ 编辑器**——编辑器有内存缓存，开着时改文件，一保存就被覆盖
- `data/*.json` 是**稀疏数组**（`null` 占位保持索引对齐），清理数据库只能置 `null`，**不能缩短数组**
- 删任何 item/weapon/skill 前，先全工程扫描事件指令中的 ID 引用
- 每次大改前：`cp -r 工程/data 工程/data_backup_$(date +%Y%m%d)`
- 合规红线：全工程已将「全能神教→拂晓教」「女基督→圣女」「女神使→神使」，新写文本不得再引入
