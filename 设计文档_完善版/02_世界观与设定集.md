## 一、双层世界结构

### 1.1 总览

```
┌──────────────────────── 心象层（幻想） ────────────────────────┐
│  穆兰雪的全世界 (Map001)                                        │
│   ├─ 空中神殿 (Map005)          ← 她的「避难所」                   │
│   ├─ 穆家园子 (Map002/008)      ← 她的「最好的记忆」                │
│   ├─ 地下迷宫 (Map013) → 迷失森林 (Map014)  ← 她不敢想的部分       │
│   ├─ 莲城 (Map020) 工厂 (Map030/032/033)   ← 她现实生活的变形     │
│   ├─ 隐秘村落 (Map041)          ← 她「可以逃走」的诱惑              │
│   └─ 心屋 (Map021) → 门        ← 出口                            │
└─────────────────────────────────────────────────────────────────┘
                              ↕ 情绪值 / 心锁 驱动
┌──────────────────────── 现实层（真实） ────────────────────────┐
│  医院 / 诊所 → 莲城某条街 → 文学的小型公寓 (Map036)              │
│  穆家园子（真实的老家，早已空置）                                │
└─────────────────────────────────────────────────────────────────┘
```

**关键**：两层用的是**同一批资产**。现实层＝同一张地图 + `OldFilmFilter` 强去色 + 去掉所有 NPC。玩家的「既视感」由此产生——**这不是省事，这是机制**（她在幻想里走的路，都是真实世界的路）。

## 二、心锁（核心道具与核心隐喻）

**〔玩家可见〕** 序章里，空中的雕像「拂晓之神·沙尔文」塞给她一把样式奇怪的旧锁，说「拿着它，怪物不敢靠近你」。锁到了她手里就开始偶尔震动，每次震动都伴随一段她记不起来的画面。

**〔真相档案〕** 心锁不是神给的。它是她**「把记忆锁起来」这件事本身**。

- 锁 = 她不愿想起来的那段现实。她越是不想面对，锁就越沉、越难打开。
- 每一次「震动」= 现实的记忆正在敲门。
- **锁从来没有被「打开」过**。终章里她把锁放在心屋的地上，然后**转身走了**——她没打开它，她只是**不再需要锁着它了**。这是全片最重要的一处「不解决的解决」。

## 三、拂晓教〔合规改写〕

> **强制改名**：原工程全部 10+ 处「全能神教 / 女基督 / 女神使」必须替换。
> 命名沿用已有的「拂晓之神·沙尔文」意象，世界观自洽度反而更高。

### 3.1 设定

| 项 | 设定 |
|---|---|
| 名称 | **拂晓教** |
| 首领称谓 | **圣女** |
| 传教者称谓 | **神使** |
| 教义 | 「拂晓之前的黑暗最长。只要守着灯不睡，天亮了就好。」 |
| 入教仪式 | 在指定地点点亮灯火（与工程已有的「点燃四处篝火」机制完美对接） |
| 组织性质 | 松散、无层级，本质是**一个互助会**，被村民想象成了「教」 |

**〔真相档案〕** 拂晓教是**她自己造出来的**。它对应的是抑郁者最常见的心理动作：**「只要找到一个外部的、比我强大的东西相信我，我就能得救。」**

所以：
- 教义的核心句「天亮了就好」——这是她对自己说的话，但她把它外包给了一个神。
- 圣女那句「这把锁来历很大，你帮我做两件事我就告诉你」——**她自己在向自己索取一个交换条件**（「我完成一个任务，就配知道真相」）。这是抑郁的典型思维：**把「被理解」变成需要赚取的东西**。
- **教里没有一个坏人。** 所有神使、教众都是被生活压垮的普通人（王姐、工人3、醉鬼、侯富、穆妈）。这是护栏 E4：**不许出现「邪恶教士」这种偷懒反派**。

## 四、拂晓之神·沙尔文

| 项 | 设定 |
|---|---|
| 形象 | 空中神殿中央的雕像，声音从头顶传来 |
| 台词定调 | 「不要恐惧黎明时的黑暗，那是通往光明的一道阶梯。」（原文保留，非常好） |
| 功能 | 给锁、教走路、唯一的「绝对善意」 |

**〔真相档案〕** 沙尔文 = **她自己求生的那部分本能**。
它是全片唯一一个**不说假话**的角色——因为它本来就是「她想活下去」这件事在说话。
终章里沙尔文不会再出现。**因为她不再需要有人告诉她「天会亮」了。**

## 五、时间线

### 5.1 玩家感知的时间线（游戏内）

第 1 天到第 7 天，白天赶路打怪，夜里写独白。

### 5.2 真实时间线〔真相档案〕

| 时间 | 事件 |
|---|---|
| 童年 | 外婆带大（井边记忆 1/12）。父母常年在外 |
| 少年 | 性格最「勇敢」的时期（对应伙伴「雪儿」） |
| 青年 | 与**文学**结婚，住在莲城的小型公寓（Map036）。「初为人妇的彷徨」（对应伙伴「兰雪」） |
| 青年末 | **第一次发病**。开始服药（氟西汀）。外婆去世 |
| 中年 | 为家庭外出工作，日复一日地辛苦（对应伙伴「阿兰」） |
| 之后 | 与文学之间出现裂缝（两个杯子，一个空着） |
| **现在** | 独居，病程反复。**某次发作后，她进入了这场持续七天的幻想**。她已经不年轻了（对应伙伴「岚哥」——她把自己最想要的「洒脱」想象成了一个男人） |
| 结局 | 她在病房/卧室里睁开眼，走出那扇门 |

> **写作注意**：以上时间线**永远不要直接讲出来**。它只能通过 12 段心锁记忆 + 4 个伙伴的话 + 独白日记，让玩家自己拼出来。

## 六、世界观写作三原则

1. **幻想世界必须「逻辑自洽但细节不对」**
   它很完整（有教派、有经济、有村庄），但总有小地方对不上——时间对不上、NPC 说出她不可能知道的信息、同一条路走两次长度不一样。**这些是缝，不是 bug。**

2. **所有「荒诞」都要能反向翻译成人话**

| 幻想里 | 现实里 |
|---|---|
| 打怪、拿宝箱、点火堆 | 一件一件做完今天必须做的事 |
| 神给了一把锁 | 我想把那段记忆锁起来 |
| 教派说「信了就能得救」 | 我太累了，我想有人来救我 |
| 四个伙伴陪我冒险 | 我把不同年纪的自己叫出来陪我 |
| 心屋没有出路 | 我把自己关起来了 |

3. **不许「解释」**
   全片禁止任何人替玩家做总结。宁可留白，不可点题。玩家的「啊，原来是这样」必须由他自己说出。
