## 〇、脚本格式约定

| 记号 | 含义 |
|---|---|
| `【序-1】` | 章节-场次编号 |
| `Map005 · 事件#18` | 该场戏在工程里的落点（**原工程事件编号，已核对**） |
| `▷ 演出` | 画面处理（tint / 移动路线 / 透明度 / 等待） |
| `◆ 指令` | 变量 / 开关 / 插件命令 |
| `〔新〕` | 本次新增的台词（原工程没有） |
| `〔改〕` | 本次修订的台词（原工程有，已订正） |
| `〔保〕` | 原工程台词，一字未改（**这些是遗产，别动**） |
| `（情绪 ＋n）` | 对情绪值的影响 |

**全局演出铁律**
1. 任何「沉默」都必须**真的给玩家时间**（`Wait 90f`，同时 tint 缓慢变暗 30f）。
2. 玩家说完话 → **先等 40 帧**再出下一句。**不要连着弹对话**。
3. 系统提示（获得物品/任务）用 `\C[6]` 灰字，**不要用感叹号**。
