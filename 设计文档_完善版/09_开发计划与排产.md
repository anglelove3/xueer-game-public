## 一、排产前提（不是建议，是排产条件）

### 1.1 按状态领活

| 状态 | 做什么 |
|---|---|
| 状态好 | 写独白 / 写剧本 / 做终章演出 |
| 状态差 | 改 JSON / 清数据库 / 删资产 / 修 Bug（**冷活**） |

> 排产表里**每天标了活的性质**：🎭 情感活 / ⚙ 冷活。状态不好就跳到下一个 ⚙ 的日子。

### 1.2 自护协议（复用 `01_GDD §9`）

- **离场仪式**：每次收工关工程，纸上写一句「今天哪一处我满意」，然后离开
- **红线**：连续 24 小时走不出来 / 冒出「必须做完才配」的念头 → 停手一周
- **外部眼睛**：每完成一章，请一个不知情的人试玩，只问「**她是一个病人，还是一个人？**」

### 1.3 时间投入

每周 15–20 小时（工作日 2h + 周末 6h）。**第四周留 buffer**，项目不赶。

## 五、风险与备选

| 风险 | 概率 | 应对 |
|---|---|---|
| 工程文件损坏 | 低 | D1 就备份 `data/`；每次大改前再备份一次 |
| 秋招/论文挤占时间 | **高** | 第四周全留 buffer；M4 未达成时**砍掉第二/四章**，保序章+一章+终章 |
| 4 个插件写不完 | 中 | `XueEr_NoResponse` 用纯事件实现（可达 80% 效果）；心魔对话也可纯事件 |
| 音频做不出来 | 中 | 先用 FreePD 免版权曲占位，作品集里注明「占位」 |
| 情绪消耗过大（本作特有问题） | **高** | 严格执行自护协议；状态差就跳冷活 |
| 母亲知情问题 | 中 | 切片完成前不告知；完成后自行决定 |
| 画面风格不统一 | 中 | 严格按 `01_GDD §10.1` 配色铁律，每章只准一个高饱和物件 |
