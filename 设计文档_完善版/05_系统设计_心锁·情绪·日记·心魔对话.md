# 系统 1 · 心锁（Memory Lock）〔P0〕

### 设计意图

把「她不愿想起」变成一件**玩家手里拿得到的东西**。玩家不是在「读剧情」，是在**一件一件把记忆捡回来**。

### 玩家体感

- 道具栏里始终有一把锁（`103 一把样式奇怪的锁`），**不可丢弃、不可使用**
- 走到特定地点，`SE: 低频嗡鸣` + 屏幕轻抖 → 闪回
- **没有任何提示告诉玩家「这里有东西可以捡」**（先给震动，闪回自动播放）

### MZ 实现

```js
// ── 变量 ──
V18  心锁计数（0-12）
V19  心锁可震动标记（0/1）
S21  心锁第N段已播放（建议用独立开关，或 S21-S32 各占一个）
```

**事件页标准结构（每个可触发点）**

```
事件页 1（出现条件：无）
  ▷ 玩家踩上/接触
  ▷ 播放 SE: 心锁嗡鸣（音量 40，0.6 秒，带 pitch +20）
  ▷ 屏幕抖动 3 帧 × 3 次
  ▷ 等待 30 帧
  ▷ 调用 公共事件：心锁闪回（参数 = 段号）
  ▷ 独立开关 A = ON
事件页 2（出现条件：独立开关 A）
  ▷ （空）
```

**公共事件「心锁闪回」标准演出序列（关键）**

```
1. 记录当前 BGM，Volume 0 淡出（60 帧）
2. Tint Screen: 0,0,0,200   （60 帧）—— 去色
3. 显示图片「记忆底框_4x3」在 (0,0)，透明度 0 → 255（30 帧）
4. 播放该段闪回图片（每张停 90–180 帧）
5. 可选：显示文字（仅第 1、2 段有台词）
6. Tint Screen: 0,0,0,0（60 帧）
7. 图片淡出（30 帧），恢复 BGM
8. 变量操作：V18 += 1
9. 等待 180 帧（❗必做：给玩家消化时间）
```

### 数值

| 项 | 值 |
|---|---|
| 总段数 | 12 |
| 强制触发（不可错过） | 3、7、12 |
| 可选触发 | 其余 9 段 |
| 每段时长 | 4–12 秒 |
| 影响 | 结局独白档位（见 `01_GDD §8.2`）+ 终章「空房间里站着 4 个人」的对照强度 |

### 边界情况

| 情况 | 处理 |
|---|---|
| 玩家漏捡可选段 | **不补、不提示、不给补救**。漏了就是漏了（这是设计，不是 bug） |
| 同一地点重复触发 | 用独立开关锁定，第二页为空 |
| 玩家在闪回中退出游戏 | 正常存档读档即可，闪回不可中断（`Wait` 期间不响应输入） |

> **⚠ 关键设计纪律**：第 12 段的「空房间」**必须悄无声息**。
> 不许加音效提示、不许闪烁、不许变色、不许变时长。它必须像一个 bug 一样悄悄过去。

# 系统 2 · 情绪值 + 心象滤镜〔P0〕

### 设计意图

把「她感受到的世界在失真」做成**玩家肉眼可见的变化**，但不给数字。

### 玩家体感

右上角一个**天气图标**（晴/多云/阴/雨/雷）。**没有条，没有数字，不解释。**

| 图标 | 数值区间 | 画面 |
|---|---|---|
| ☀ 晴 | 80–100 | 高饱和，日光泛光 |
| ⛅ 多云 | 60–79 | 轻微偏冷 |
| ☁ 阴 | 40–59 | 明显灰调 + 暗角 |
| 🌧 雨 | 20–39 | 去色 + 噪点 |
| ⛈ 雷 | 0–19 | 强去色 + 重噪点 + 边缘压黑 |

> **工程已有 `2D_Cat_BeautifulSunshineFilter` 与 `2D_Cat_OldFilmFilter`，直接用作两端的「档位源」，中间档用 `Tint Screen` 插值。**

### MZ 实现

```js
V20  情绪值（0-100）
```

**每帧刷新（公共事件，并行进程，或插件）**

```
天气图标 = 
  情绪值 >= 80 ? 晴
: >= 60 ? 多云
: >= 40 ? 阴
: >= 20 ? 雨
: 雷
```

**滤镜插值（用 `Tint Screen` 逼近，避免插件反复调用）**

```
Tint Screen R,G,B,Gray =
  情绪值 80-100  → 0,   0,   0,   0        （+ SunshineFilter ON）
  情绪值 60-79   → -15, -15, -10, 20
  情绪值 40-59   → -45, -45, -35, 60
  情绪值 20-39   → -75, -75, -60, 120
  情绪值 0-19    → -110,-110,-100,160      （+ OldFilmFilter ON）
```

### 数值（增减表）

| 行为 | Δ |
|---|---|
| 和母亲吃一顿饭 | ＋2 |
| 收集一个记忆碎片 | ＋4 |
| 完成一个小任务（发卡/蜜饯） | ＋3 |
| 夜里写独白（读完全部） | ＋3 |
| 露宿/在森林里久坐 | －2 |
| 目击争吵（莲城街头） | －3 |
| **发现买药单（Map036）** | **－15** |
| 被心魔击中（对话战答错） | －5 |
| 战斗结束（无论胜负） | －1（**每场都扣，打赢也扣**） |

> **★铁律落地**：「打赢也扣 1」。

### 边界情况

| 情况 | 处理 |
|---|---|
| 情绪值触底 0 | **不死亡、不 Game Over**。只把滤镜拉到最狠，并把所有 NPC 的对白换成「今天的短版本」 |
| 情绪值封顶 100 | 上限锁死，避免「越打越开心」的错觉 |
| 玩家想看数字 | **永远不给**。想查就去看右上角 |

# 系统 3 · 独白日记（Monologue）〔P0〕

### 设计意图

**这是游戏标题的落点。** 目前工程里**一个字都没有**——这是最大的缺口。

### 玩家体感

- 每晚自动触发，**不可跳过**（可以快速点过去，但翻页音会一直在）
- 菜单里可随时回看（新增菜单项「独白」）
- 日记内容按当天行为选变体

### MZ 实现

```js
S33  第1夜已读 / S34 第2夜 / … / S37 第终夜
```

**菜单新增项**：建议用公共事件 + 图片列表实现（不改核心脚本），或给 `MOG_SceneMenu` 加一条命令。

**排版（`img/pictures/日记本.png`）**

```
┌────────────────────────────┐
│                            │
│   今天……                    │  ← 逐字打印（2D_Cat_MsgTextPrintAnim）
│                            │
│                            │
│              第 3 夜        │
└────────────────────────────┘
```

### 数值

| 项 | 值 |
|---|---|
| 篇数 | 5（4 夜 + 终夜） |
| 每篇字数 | 120–300 字 |
| 变体数 | 第 1 夜 3 个，第 2 夜 2 个，第 3 夜 2 个，第 4 夜 1 个，终夜 3 个（= 结局档位） |
| 每篇时长 | 25–50 秒 |

### 写作规则（硬性）

见 `04_剧情脚本 · 附录 A`：≥1 个具体物件 / 无「抑郁/病/治疗」字样 / 结尾不说完 / 不用感叹号。

### 边界情况

| 情况 | 处理 |
|---|---|
| 玩家在菜单里反复看 | 允许，不加任何奖励（**不做收集率**） |
| 玩家跳过没看 | **不惩罚、不提示**。但结束时会少一段「她今天说的话」 |

# 系统 4 · 心魔对话（替代战斗）〔P0〕

### 设计意图

把「抑郁的认知扭曲」做成**可玩的对抗**，同时**不给胜利的快感**。

### 玩家体感

- 遭遇敌人仍是原工程的明雷/暗雷（保留 RPG 骨架）
- 进战斗后：**没有「攻击/技能/物品/逃跑」**，只有一句心魔的话 + 3 个回应
- 打赢后**不弹「胜利」**，只弹一句「**她撑住了今天。**」

### MZ 实现（用事件演出替代 Troops）

**方案 A（推荐，轻量）**：保留 `Troops.json` 用于承载画面，但把战斗事件改为纯事件演出。

**心魔对话标准流程**

```
事件：遭遇心魔 N

1. 旁白（灰字，无名）：      一句话
       例：「你今天什么都没做成。」
2. 无限循环 → 选项（3 选 1）：
       ① 反驳      → 心魔「强度」 -2，情绪值 -5
       ② 认同      → 心魔「强度」 +1，情绪值 +8
       ③ 沉默      → 无变化，等待 120 帧（❗真的等）
3. 判定：
       心魔强度 <= 0 → 结束（不显示「胜利」）
       玩家情绪值 <= 0 → 结束（不显示「失败」）
       循环上限 5 轮
4. 收尾：
       一律显示：「她撑住了今天。」
       Variables[情绪值] -= 1
```

**心魔台词库（每只心魔 4–6 句，按已有敌人条目复用）**

| 心魔 | 台词 |
|---|---|
| 心魔（敌 6/11） | 「你不值得被爱。」「你拖累了所有人。」「他们只是客气。」「你笑的时候在演。」 |
| 大眼虫 | 「所有人都在看你。」「他们在议论你。」 |
| 狼人 | 「你早就烂掉了。」「别装了。」 |
| 变异人 | 「你以前不是这样的。」 |
| 邪零巫师 | 「你连自己都骗。」「你知道这是假的。」 |
| boss1 | 「你以为你能赢？」「你赢了，然后呢？」 |
| 全能神教教众 → **拂晓教信徒** | 「信了就好了。」「你为什么还不信。」 |

**玩家的 3 个回应（固定）**

| 回应 | 效果 | 设计意图 |
|---|---|---|
| **反驳** | 心魔 -2，情绪 -5 | 反击要付出代价（这是真的） |
| **认同** | 心魔 +1，情绪 +8 | 「承认它」有时反而好受一点（这也是真的） |
| **沉默** | 无变化，等 2 秒 | **沉默是机制，不是留白** |

### 数值

| 项 | 值 |
|---|---|
| 心魔初始强度 | 6（小怪）/ 12（精英）/ 20（boss1） |
| 单轮耗时 | 反驳 4s / 认同 5s / 沉默 7s |
| 上限 | 5 轮（**打不完就结束，不给死循环**） |

### 边界情况

| 情况 | 处理 |
|---|---|
| 5 轮未归零 | 直接收尾，**不判负**。台词：「今天先到这儿。」 |
| 玩家全部选「沉默」 | 允许。**沉默也是一种打法**，只要撑过 5 轮也算结束 |
| 全游戏全部打赢 | **不改变任何结局**（这是铁律 3） |

# 系统 5 · 力气（Capacity）〔P1〕

> **来源**：吸收自 `GDD_v0.2` / `开发方案`。原文设计得很好，直接沿用。

### 设计意图

不是「爱得够不够」，是「**力气还剩多少**」。

| 行为 | 消耗 / 恢复 |
|---|---|
| 陪人坐 1 个时段 | －15 |
| 做饭 / 提醒吃药 | －10 |
| 自己吃饭、睡觉 | ＋20 |
| 上班 | －5（并 ＋金币） |

**关键**：每个 NPC 每天能接受的照料**有上限（30 点）**。超过之后回应质量下降——**不是拒绝，是「接不住」**。

### MZ 实现

```js
V21  力气（0-100）
V22  今日照料已用（每日重置）
V23  当前时段（0=白天 1=黄昏 2=夜）
```

**每日重置**：`Map007` 醒来的事件里 `V22 = 0`。

**表达方式（重要）**：力气 < 20 时，选项**不是变灰，而是直接消失**，并给一句独白：

> **雪儿**：（我没什么力气说话了。）（然后只剩「坐着」这一个选项）

### 边界情况

| 情况 | 处理 |
|---|---|
| 力气归零 | 当天强制结束（直接跳到夜）**不惩罚**，只是「今天就到这儿」 |
| 玩家反复撞上限 | **这正是在教玩家**「我今天只能到这里」——不要移除这个摩擦 |

# 系统 6 · 无响应对话〔P1〕

> **来源**：吸收自 `GDD_v0.2` / `开发方案`。原设计「说话→等待→可能没回应」，保留。

### MZ 实现（新增插件命令 `<NoResponse:90>`）

```js
// XueEr_NoResponse.js 核心逻辑
PluginManager.registerCommand('XueEr_NoResponse', 'noResponse', args => {
  const frames = Number(args.frames || 90);
  $gameScreen.startTint([0,0,0,120], 30);
  $gameMessage.setWaitMode(...); // 等待 frames 帧
});
```

**事件里这样写：**

```
显示文字：雪儿：妈，今天怎么样？
▷ 插件命令：XueEr_NoResponse frames = 90
▷ 屏幕 tint：0,0,0,120（30 帧）
▷ 等待 90 帧        ← 玩家可以按确定跳过，但跳过不减分
▷ 屏幕 tint：回复
显示文字：穆妈：……没事。
```

### 教学关（必做）

**第一次和母亲对话，无论选什么，她都只说「没事」。**
教学目的：**教会玩家「你改变不了她，你只能选择在场」**。

### 边界情况

| 情况 | 处理 |
|---|---|
| 玩家狂按确定 | 允许跳过。**跳过不会错过任何东西**（因为本来就没有东西） |
| 玩家以为卡死 | 在等待期间**不要让画面完全静止**：tint 在缓慢变化 + 环境音一直在，玩家能感知到「游戏在走」 |

> **★关键**：沉默期间**绝对不能出现「（……）」这种提示文字**。让画面自己说明一切。

# 系统 7 · 关系回暖 / 倒退〔P1〕

### 设计意图

**她不会怪你，她只会更安静。** 而玩家大概率不会发现。

### MZ 实现

```js
V24  穆妈关系（0-5，初始 1）
V25  当日是否与穆妈对话过（每日重置）
```

**每日结束（公共事件）**

```
if (V25 == 0) { V24 -= 1 }   // 没主动接触 → 回落
V25 = 0
```

**表现（永不显示数字）**：靠**称呼**变化

| V24 | 母亲对她的称呼 |
|---|---|
| 5 | 「小雪」 |
| 3–4 | 「雪儿」 |
| 1–2 | 「丫头」 |
| 0 | 不叫，只用「你」 |

**回落提示（必须极其微弱）**：母亲多了一个动作——**把椅子往里挪了一点**（移动路线 1 格，无音效，无台词）。

> **★这是全片最狠的一处设计**：玩家不会注意到，但会觉得「今天有点冷」。说不出为什么。

### 边界情况

| 情况 | 处理 |
|---|---|
| 关系归零 | 不触发任何「坏结局」。只是终章她的那一句「妈」更说不出口 |

# 系统 8 · 记忆不可靠〔P2〕

### 设计意图

服务于终章「**我是不是原因之一**」——孩子永远无法确认。

### MZ 实现

```js
// 每次播放回忆时，1/2 概率随机抽一个版本
V26  记忆版本号（1 或 2，随机）
```

```
条件分支：V26 == 1
  → 显示回忆 A：「那年我八岁，妈带我去看电影。」
条件分支：V26 == 2
  → 显示回忆 B：「那年我十二岁，妈带我去看电影。」
```

**其余手法**
- `OldFilmFilter` 强档
- 回忆段落的**文字位置轻微错位**（`\C[]` 与 `\}` 控制，或直接用两条不同位置的图片）

### 铁律

**永远不给正确答案。** 不出现「其实你记错了」这种台词。
