## 1. 一句话定位

### Logline

> **她把自己关进了一个能打赢的世界。**
> 一个抑郁症患者在心里搭了一座城，把四个年龄段的自己找齐，然后第一次试着，从里面走出来。

### 副标题（可选）

**《一位抑郁症患者的独白 —— 穆兰雪的七天》**

### 电梯陈述（90 秒体验承诺）

> 你扮演**穆兰雪**，朋友都叫她雪儿。某天她在一座天上飘着的城堡里醒来，身后有两个东西在追她，一个叫「拂晓之神」的雕像塞给她一把旧锁，说「拿着它，怪物就不敢靠近你了」。
> 她回到了熟悉的村子，妈妈在等她吃饭，邻居小娟的发卡丢了，老太太塞给她一包蜜饯。一切都很好——好得有点不对劲。
> 村子外面，一个自称「拂晓教」的教派正在传教，说世界要完了，只要信就能得救。教里的圣女说：把锁给我，帮我做几件事，我就告诉你这把锁是什么。
> 你信了她。你找了三个伙伴一起上路：一个爱哭的贵族小姐、一个带着孩子上班的中年女人、一个喝酒打架的泼皮。你们打怪、拿宝箱、点篝火、找发卡——像所有 RPG 一样。
> 然后有一天，你在城里一间小公寓的抽屉里，翻到一张买药单。上面写着**氟西汀**，签名是「穆兰雪」。
> 到那一刻你才想起来：这座城里没有别人。

## 2. 设计铁律（不可妥协）

| # | 铁律 | 落地约束 |
|---|---|---|
| 1 | **不撒谎，也不给「治愈」** | 结局不出现「她好了」。只出现「她今天愿意走出那扇门」 |
| 2 | **幻觉是她的自我保护，不是骗局** | 幻想世界的荒诞必须能被解读为「她在给自己造一个能赢的地方」，而不是「作者编得烂」 |
| 3 | **玩家是见证者，不是医生** | 玩家的所有输入只改变「这一刻的质量」，不改变「病的结果」；没有「治疗进度条」 |
| 4 | **是「力气不够」，不是「不爱」** | 所有冷漠/沉默的 NPC 表现必须能被解释为容量问题 |
| 5 | **具体细节大于抽象抒情** | 药盒、买药单、没洗的碗、说三遍的「我没事」、突然停下的半句话——具体名词优先于形容词 |
| 6 | **荒诞要留缝** | 每章至少埋 1 处「不对劲」（时间对不上 / NPC 说漏嘴 / 同一句台词两个版本），但永远不给「正确答案」 |

**禁令**：不写「抑郁是意志力问题」；不写「只要坚持就会好」；不做收集率百分比；不做成就；不做「抑郁=坏结局」的因果暗示。

## 3. 目标玩家 / 对标 / 差异化

### 3.1 目标玩家

- 20–35 岁，玩过《去月球》《伊森卡特的消失》《艾迪芬奇的记忆》《重返猴岛》的叙事向玩家
- 对「心理/内省/家庭」题材有共鸣的人
- 做过 RPG Maker、看得懂「素材复用」的自制游戏玩家（本作对他们是「同行」,能看懂技法）
- **不追求战斗爽感**的玩家

### 3.2 对标

| 对标 | 借鉴点 | 明确不抄 |
|---|---|---|
| 《去月球》 | 记忆碎片推进、把「人生」做成可回放段落 | 不做催泪现场 |
| 《艾迪芬奇的记忆》 | 一个「家族」就是一套机制；每个成员一种玩法 | 不做高概念演出 |
| 《赛博朋克 2077》DLC「幻灭」 | 幻觉伙伴逐渐暴露出「他们只在你看得见时存在」 | 不做悬疑反转秀 |
| 《OMORI》 | 明亮幻想世界 = 心理防御机制；黑暗现实层对照 | **不做恐怖 jump scare**（本作不吓人） |
| 《极乐迪斯科》 | 内心对话作为主要玩法 | 不做长篇政治文本 |

### 3.3 差异化（三条，也是简历上要写的那三条）

1. **四个可操作角色 = 同一个人生的四个阶段**
   雪儿（少女·勇敢）/ 兰雪（青年·初为人妇的彷徨）/ 阿兰（中年·为家庭辛劳）/ 岚哥（老年·看开的洒脱）。
   战斗里他们换的是「人格」，不是职业；队伍编成 = 她今天用哪几个自己在过日子。
   **岚哥是男性形象**——因为她把自己最想要的「什么都不在乎」想象成了一个喝酒打架的粗嗓子男人。

2. **RPG Maker 做了一个「不值得打赢」的战斗系统**
   所有战斗都打赢也不改变病情。战斗界面里没有「胜利」提示，只有「她撑住了今天」。Boss 战 = 心魔对话，选对话选项而非技能。

3. **「心锁」驱动的画面对照**
   地上捡的道具能开记忆。每开一段，就闪回一段**黑白低饱和的真实记忆**（高饱和幻想 vs 去色现实）。玩家是自己拼出真相的。

## 5. 核心循环

```
[现实层/幻想层] 探索地图 → 与 NPC 对话 → 触发事件
        ↓
情绪值波动（对话选项 / 独白 / 心锁解锁 影响）
        ↓
情绪值越界 → 画面滤镜变化（自我感知失真）
        ↓
特定地点 → 拾取心锁记忆碎片 → 播放黑白闪回
        ↓
夜 → 独白日记（玩家读到她今天真正想说的话）
        ↓
次日，NPC 的称呼与态度发生变化（关系隐性增加/倒退）
```

**关键设计**：循环里**没有「变强」**。玩家的成长曲线是「**越来越看得懂她在说什么**」，不是「数值越来越高」。

## 8. 结局设计

### 8.1 只有一个结局（沿用《开发方案》的正确判断）

**讨好的「三结局」必须砍掉**。理由：给「抑郁」配一个「沉沦结局」，等于在作品里宣判「不努力就会烂掉」，这是对目标玩家最大的冒犯。

### 8.2 结局的「分层」——不是多结局，是同一结局的三种读法

结局画面完全相同（她走出门 → 晨光），但**最后一行独白**按玩家通关状态不同：

| 玩家状态 | 最后一行独白 | 含义 |
|---|---|---|
| 心锁 ≥ 9 段 + 关系值高 | 「我把门推开了一条缝。风是凉的。**我居然是活的。**」 | 她确认了自己还在 |
| 心锁 5–8 段 | 「我把门推开了一条缝。风是凉的。明天我再推一次。」 | 她知道会反复 |
| 心锁 < 5 段 | 「我把门推开了一条缝。风是凉的。……**就到这里吧。**」 | 她今天只到这里 |

**三条都是好结局。** 差别只在「她今天走了多远」。

## 9. 伦理护栏（自传体/真实题材项目专属）

| 编号 | 护栏 | 验收标准 |
|---|---|---|
| E1 | **病不是「人格」** | 四个伙伴可以各有缺点，但**都不能只有「病人」一个标签**；每人至少 3 个与病无关的具体习惯 |
| E2 | **不出现医学诊断** | 全片只在**道具（买药单）**上出现一次药名，角色口中永远不说「我有抑郁症」 |
| E3 | **她保有主动性** | 终章揭示真相的台词必须是**她自己说出口**的，不能由「另一个雪儿」代说 |
| E4 | **不美化也不妖魔化教派** | 拂晓教信徒必须**全是被生活压垮的普通人**，不能出现「邪恶教士」这种偷懒反派 |
| E5 | **不消费痛苦** | 禁止使用「割腕/自伤特写」作为演出；所有痛苦靠留白和道具暗示 |

### 开发者自护协议（排产前提，非建议）

- **按状态领活**：状态好 → 写独白/剧本；状态差 → 改 JSON/清理数据/删脏资产
- **离场仪式**：每次收工关工程，在纸上写一句「今天哪一处我满意」，然后离开
- **红线**：连续 24 小时走不出来 / 冒出「必须做完才配」的念头 → 停手一周，找真人说
- **外部眼睛**：每完成一章，请一个不知情的人试玩，只问一个问题：「**你看完觉得她是一个病人，还是一个人？**」

### 10.1 视觉

| 层 | 处理 | 现有插件 |

| 记忆闪回（黑白） | 全去色 + 强颗粒 + 4:3 黑边 | 复用上两个参数化 |
| 现实层（尾声） | 极低饱和 + 高亮，接近「过曝」 | 同上 |
| 视差背景 | 天空城、云层 | `ulds` ✅ 已有 |

**配色铁律**：全片饱和度统一压低，**每章只准一个高饱和物件**：
- 一章＝红色搪瓷杯（母亲的道具）
- 二章＝心锁的微光（青金色）
- 三章＝买药单上的红章
- 终章＝门缝里的白光

### 10.2 UI

- 菜单沿用 `MOG_SceneMenu` 系列（工程已有），但**不显示任何数值条**
- 情绪值不做进度条 → 做成**右上角天气图标**：晴 / 多云 / 阴 / 雨 / 雷（玩家意会，不给数字）
- 独白日记做成**翻开的笔记本**，一夜一页
- 存档界面：「今天」（而不是「存档 1」）
