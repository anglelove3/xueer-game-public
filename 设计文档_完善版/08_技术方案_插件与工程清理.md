## 五、新写插件（4 个）规格

> 全部放在 `js/plugins/`，命名前缀 `XueEr_`。

### 5.1 `XueEr_MentalLock.js`（心锁）

| 项 | 内容 |
|---|---|
| 目的 | 承载 12 段记忆的解锁与闪回演出 |
| 命令 | `MemLock play <段号>` / `MemLock count` |
| 数据 | `$gameVariables.value(18)`（心锁计数） |
| 核心 | 滤镜去色 → 图片 4:3 黑边 → 逐图播放 → 恢复；结束后 `V18 += 1` |
| 参数 | 每段时长、图片前缀、是否给台词 |

```js
// 结构示意（非完整代码）
(() => {
  const P = PluginManager.parameters('XueEr_MentalLock');
  PluginManager.registerCommand('XueEr_MentalLock', 'play', args => {
    const id = Number(args.id);
    $gameScreen.startTint([0, 0, 0, 200], 60);
    // …播放图片序列…
    $gameScreen.startTint([0, 0, 0, 0], 60);
    $gameVariables.setValue(18, $gameVariables.value(18) + 1);
    $gameSwitches.setValue(20 + id, true);   // S21..S32
  });
})();
```

### 5.2 `XueEr_MoodMeter.js`（情绪值 + 天气图标）

| 项 | 内容 |
|---|---|
| 目的 | 按情绪值自动切换滤镜档位 + 右上角天气图标 |
| 命令 | `Mood set <值>` / `Mood add <值>` |
| 数据 | `$gameVariables.value(20)` |
| 核心 | 每 30 帧检查一次，仅在**档位变化时**调用 `startTint`（避免每帧调用） |
| UI | 右上角 32×32 图标（`img/system/MoodIcon_*.png`，共 5 张） |

> **性能注意**：**不要每帧 setTint**。只在跨档时调用，跨档前后各做 60 帧过渡。

### 5.3 `XueEr_Monologue.js`（独白）

| 项 | 内容 |
|---|---|
| 目的 | 全屏笔记本 UI + 逐字打印 + 菜单回看 |
| 命令 | `Mono night <夜号>` / `Mono menu` |
| 数据 | `$gameSwitches.value(32 + night)`（S33–S37） |
| 核心 | 显示 `日记本.png` → 逐字打印 → 等待确认 → 关闭 |
| 变体 | 按 `V20 / V24 / 开关` 在事件里做分支选择文本，插件只管**显示** |

### 5.4 `XueEr_MindTalk.js`（心魔对话）

| 项 | 内容 |
|---|---|
| 目的 | 替代战斗结算：无攻击、无血条、无「胜利」 |
| 命令 | `MindTalk start <强度>` |
| 核心 | 循环：显示心魔台词 → 3 选项 → 结算 |
| 关键 | **战斗结束时永不显示「胜利/失败」**，只显示 `她撑住了今天。` |
| 调用 | 原工程的 `Troops.json` 保留但不再被常规战斗触发；改由地图事件调用本插件 |

**伪代码**

```
start(strength):
  hp = strength
  for round in 1..5:
    showLine(pickEnemyLine())
    choice = ask([「反驳」, 「认同」, 「沉默」])
    if choice == 反驳: hp -= 2; mood -= 5
    if choice == 认同: hp += 1; mood += 8
    if choice == 沉默: wait(120)
    if hp <= 0: break
    if mood <= 0: break
  end:
    showText(「她撑住了今天。」)     // ← 没有「胜利」
    mood -= 1                      // ← 打赢也扣
```

### 5.5 （可选）`XueEr_NoResponse.js`（无响应对话）

见 `05_系统设计 §6`。若不想写插件，**用纯事件实现**（`Wait` + `Tint` + 允许按键跳过）也能达到 80% 效果。

## 八、性能与稳定性

| 风险 | 措施 |
|---|---|
| 滤镜叠加性能差 | **同屏最多 2 层滤镜**（Sunshine + OldFilm 二选一 + 1 层 Tint），不要三层同开 |
| 心锁闪回大量图片 | 图片预加载（`ImageManager.loadPicture` 在使用前 1 秒预加载） |
| 天气 + 粒子 + 滤镜 | 心象层**关掉天气**；现实层**关掉粒子** |
| 存档体积 | 12 段闪回只存开关（12 个 bool），不存图片 |
| 中文字体 | 确认 `fonts/` 下的字体覆盖生僻字（「搪」「瓷」「氟西汀」） |
