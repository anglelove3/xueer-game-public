# 脚本索引

> 本目录是《一位抑郁症患者的独白》重构过程中用到的**可复用脚本与数据导出**。
> 全部 Python 脚本用 Python 3 运行；示例命令在仓库根目录执行。
> 脚本通过 `scripts/_paths.py` 定位仓库内的 `工程/`，clone 到任意目录即可运行。
> `process_memory_images.py` / `process_title.py` 使用 Windows 自带字体（simsun / simkai），非 Windows 环境需自行指定字体文件。

## 一、探查 / 扫描类（只读，安全）

| 脚本 | 作用 |
|---|---|
| `probe_mz.py` | 工程体检：地图/事件/指令/对白行数、插件注册数等实测统计 |
| `probe2.py` | 结构探查：说话人段落、事件页条件等 |
| `verify_audit.py` | 施工图断言 vs 工程实测的批量核对 |
| `dump_db.py` | 导出各数据库（Items/Weapons/Skills/Actors…）的名录与 ID |
| **`scan_refs.py`** | **★ 全工程 ID 引用扫描**：把每条 ID 被谁引用逐个列出，产出 `C节_ID引用扫描报告.md`；删任何条目前必跑 |
| `dump_text.py` | 导出全部 ShowText(401) 按 事件页 拼成整段 + 语病打标 → `story_lines.txt` |
| **`dump_runs.py`** | **★ 按「同一说话人下连续 401 段落」导出对白** → `runs.txt`（批量改对白的定位单位） |
| `analyze*.py` (×4) | 早期（2026-10-07）的初版分析脚本 |
| `extract_story.py` / `docx_text.py` | 从原始论文 docx 抽取正文（论文含个人信息，未随公开仓库提供） |

| `游戏文档.txt` | 原始论文纯文本（含个人信息，仅本机留存，未入库） |

## ⚠ 三条通用铁律（脚本已按此编写）

1. **事件页条件里 `itemId`/`actorId` 有默认值 1** —— 未启用的条件靠 `itemValid`/`actorValid` 区分，不验标志位会得到海量假阳性。
2. **长台词会被切成多条 `401` 指令** —— 残留词/改名复查**不能只 grep 裸文本**，必须把一页内连续 401 拼成整段再查；裸文本替换也修不了被拆开的词。
3. **改内存后必须立刻落盘并重新 `load` 复核** —— 漏 `save` 会被后续步骤重新 `load` 覆盖。
