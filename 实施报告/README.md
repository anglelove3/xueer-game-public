## ⚠ 数据层数字口径

施工图（尤其 `06_数值与数据表`）里的条目数是从**论文 §4.4** 转抄的，且口径是「**有名字的条目数**」而非**数组长度**；
工程里躺着未删减的 **MZ 官方示例数据库**，因此数组长度 = 有名字条目 + 官方示例。
**凡涉及 ID / 数量 / 清理的操作，一律以本目录第 3–5 份报告为准。**
