## 2. 插件行为与参数（当前生效值）

### 2.1 情绪值 `XueEr_MoodMeter`

- 变量 V20；新游戏初始 55；每 30 帧检查一次。
- 档位（从低到高）：**雷 0–19、雨 20–39、阴 40–59、多云 60–79、晴 80–100**。
- 只有跨档才启动 60 帧 Tint 过渡；心锁播放期间收到的档位变化会挂起，结束后再应用。
- 图标 32×32，距右 16、Y 16、透明度 220，挂在 `_spriteset` 上，随地图创建/销毁。
- 事件命令：`Mood set value=90`、`Mood add value=-15`、`Mood refresh`、`Mood get`（控制台）。

### 2.2 心锁 `XueEr_MentalLock`

- 事件命令：`MemLock play id=1`、`MemLock play id=7 images=Memory_7_1,Memory_7_2`、`MemLock play id=12 silent=true`、`MemLock count`、`MemLock reset`（仅开发）。
- 段号 1–12；已打开 S20+id 时直接跳过；播完 V18+1、打开对应开关、BGM 恢复。
- 默认时间线：进入 60 帧 → 每张图淡入 30 + 停留 120 + 淡出 30 → 退场 60 → 消化 180 帧。命令会阻塞事件直到整段结束。
- 默认图名 `Memory_%1_%2`；`silent=true` 时不播 SE、不抖屏、不去色、不显示边框（给第 12 段「空房间」用）。
- 当前参数：边框 `记忆底框_4x3`、Tint `0,0,0,180`、SE `Darkness2` 40%/70%、抖屏 3/5/30、BGM 淡出 1.2 秒。

### 2.3 独白 `XueEr_Monologue`

- 事件命令：`Mono night night=1 variant=1`、`Mono menu`、`Mono get`（控制台）。
- 读完打开 S32+night（S33–S37）；情绪 +3 **刻意不放在插件里**，由事件层在关闭后执行 `Mood add value=3`，避免回看重复加值。
- 菜单项「独白」只在该存档至少读过一夜后出现；列表固定五夜，未读显示「（未读）」且不可选。
- 文字框 672×472，位于 (102,76)，字号 22，3 帧/字；X=102 是为了让正文避开日记本红线。
- 菜单进入后按取消返回菜单；回看结束后原样回到菜单列表。

### 2.4 心魔对话 `XueEr_MindTalk`

- 事件命令：`MindTalk start strength=6 set=心魔`、`MindTalk get`（控制台）。
- 规则：反驳 强度−2 / 情绪−5；认同 强度+1 / 情绪+8；沉默不变、真等 120 帧。
- 结束条件：强度 ≤0、情绪 ≤0、或满 5 轮；结束一律情绪 −1，永远不显示「胜利 / 失败」。
- 台词组：心魔 / 大眼虫 / 狼人 / 变异人 / 邪零巫师 / boss1 / 拂晓教信徒。
- 这是地图事件里的对话演出，**不进入 `Scene_Battle`**，因此 Troops 的战斗设置不会被触发。

### 2.5 KoTC 兼容补丁（本轮排障产物）

`SceneManager.push` 打开独白场景时，MZ 会销毁旧 `Scene_Map`；KoTC 把全局小地图精灵挂在地图场景上，返回地图后继续操作已销毁的精灵，导致 `onMapLoaded` 抛异常、`_mapLoaded` 永远不置真、地图每帧重建显示对象，事件解释器卡死。补丁做三件事：切出地图前摘下小地图；地图加载时清掉重复刷新计时器；精灵若已被销毁则跳过刷新。修复后验证全程 0 条异常。

## 4. 本轮修掉的问题

1. **空回看列表**：`Window_Command.refresh()` 会先清空列表再调空 `makeCommandList()`，手动 `addCommand` 后刷新反而全没。改为 `Window_MonologueList.makeCommandList()` 建项，构造时自动刷新；窗口高度 236→264，五夜不再需要滚动。
2. **正文压日记本红线**：文字框 X 72→102（插件默认值与工程参数同步），正文起点约 118 px。
3. **心锁截图总拍不到记忆图**：测试时钟把 `1000/60` 当成 delta，游戏逻辑 2 倍速，截图落在时间线尾。改为 `SceneManager.update(1)` 后正常。
4. **切场景卡死地图**：即 2.5 的 KoTC 生命周期问题，以兼容插件修复。
