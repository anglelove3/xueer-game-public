# 跨电脑开发指南（GitHub · xueer-game-public）

> 仓库：**https://github.com/anglelove3/xueer-game-public**（公开仓库，账号 anglelove3）
> 工程在仓库里的位置：`工程/Game.rmmzproject`

## 当前状态

最新提交已全部推上 GitHub（基线快照 + 批次1 合规改名），本机无欠账——**新电脑直接 clone 即可，不用先 push**。

## 另一台电脑：一次性准备（3 件）

1. 装 **RPG Maker MZ**（Steam 同账号下载）+ **Git**（git-scm.com，默认一路下一步）
2. 公开仓库可直接 clone；要推送时再用浏览器登录 GitHub 授权（凭据管理器自动记住，只此一次）
3. 顺手开 **2FA**：GitHub → Settings → Password and authentication（2026-11-19 前强制）

## 克隆（逐条执行）

```bash
cd /d                          # 想放哪个盘就进哪个盘（D 盘为例）
git clone https://github.com/anglelove3/xueer-game-public.git    # 约290M，等几分钟
cd xueer-game-public
```

然后用 MZ 打开 **`工程/Game.rmmzproject`**——地图/数据库/插件/全套设计文档都在，接着开发。

## 日常两台电脑切换：三个动作

| 时机 | 命令 | 说明 |
|---|---|---|
| **开工** | `git pull` | 把另一台电脑推的改动拉下来 |
| **改 data 前** | **关掉 MZ 编辑器** | 编辑器有缓存，开着改=白改 |
| **收工** | `git add -A` → `git commit -m "改了啥"` → `git push` | 三连，缺一不可 |

## 红线

- push 被拒 → 先 `git pull` 再重新 push（说明另一台电脑有新提交）；冲突了发给 AI 解
- **别两台电脑同时开工**——开工 pull、收工 push 就不会撞车
- 仓库里没有 `Game.exe` 是正常的：播放测试用 MZ 自带运行时；出可执行成品用编辑器的"部署"功能
- 大改前照旧备份：`cp -r 工程/data 工程/data_backup_日期`（本地备份已 gitignore，不进仓库）
