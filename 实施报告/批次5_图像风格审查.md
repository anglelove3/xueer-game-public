## 1. 先给结论

> 本节及第 2–10 节的取样对象是**路线 B 之前的照片层素材**；路线 B 后的实际画面见第 11 节与 `09–11` 号证据板。

分三层看，不要只问「是不是像素风」：

| 判断口径 | 结论 |
|---|---|
| 严格按「像素风动漫」 | ❌ 12 张回忆、尾声、标题都不是像素画，也不是动漫插画，是黑白/低饱和摄影。 |
| 按设计文档的「幻想 vs 现实」 | ✅ 黑白回忆、4:3 黑边、强颗粒、过曝尾声，全部符合 GDD 第 10 节；这是刻意做旧、刻意去色的。 |
| 按玩家第一眼观感 | ⚠️ 幻想世界是彩色像素 + Q 版小人，角色头像却是高分辨率动漫；回忆和标题又变成摄影。玩家能看出「回忆是另一个世界」，但不一定能看出「这是同一个游戏」。 |

所以真正的问题不是「黑白」，而是：

1. **摄影质感 vs 动漫/像素质感**——记忆和标题里是真人照片级的皮肤、头发、布料，游戏里是动漫脸和像素小人。
2. **标题界面有两套命令文字叠在一起**——左边是默认标题窗口「重新开始 / 继续游戏 / 选项」，右边是 MOG 图片命令「开始 / 继续 / 设置」，而且左边窗口的绿藤/紫蓝皮肤和标题的灰褐色调冲突。（**已修**，见第 10.1 节）
3. **回忆播放时情绪云 HUD 没有隐藏**——右上角的云是情绪值 HUD，不是水印；它出现在 4:3 黑边里，会破坏「记忆画框」的沉浸感。（**已修**：情绪云与地图菜单按钮都会隐藏，见第 10.2 节）
4. **Memory_10 太暗**——全图 57.6% 的像素接近纯黑，在截图里主体几乎看不清；Memory_4 / 2 / 9 也偏暗，但还能辨认。（**已提亮**：平均亮度 16.3 → 31.9，近黑 57.6% → 33.8%）
5. **人物对不上**——游戏里的雪儿是金发动漫脸；黑白回忆里是黑发真人女性。除非设定明确说「幻想里的金发是她的自我美化，现实里的黑发才是真身」，否则玩家很难把两张脸认成同一个人。

另：**没有发现残留水印。** 右上角白色/蓝色云朵是 `XueEr_MoodMeter` 的情绪 HUD；14 张入库图的四角已检查，源图水印仍只留在 `批次5_素材源/` 归档里。

## 2. 游戏实际有 6 种画面语言

这很重要：游戏本来就不是「纯像素风」，而是分层的。

| 层 | 画面 | 实际风格 |
|---|---|---|
| 幻想世界 | Map005 / Map019 等 | RPG Maker 像素地图 + 动漫 Q 版行走图，高饱和、亮色 |
| 角色身份 | 对话框头像 | 高分辨率动漫插画，144×144 脸图，不是像素 |
| 内心独白 | 第 1–5 夜 | 米色纸张 + 横线 + 衬线字，像日记本 |
| 真实记忆 | 12 段心锁 | 黑白摄影、4:3 黑边、强颗粒、像素星框 |
| 现实尾声 | Map036 醒来 | 过曝、低饱和摄影 |
| 标题 | Title_Main | 灰褐摄影 key art + 书法标题 |

对照板：[01_六层画面语言.png](批次5_风格审查/01_六层画面语言.png)

**这套分层本身是有设计依据的**：GDD 明确写「高饱和幻想 vs 去色现实」「记忆闪回：全去色 + 强颗粒 + 4:3 黑边」「现实层：极低饱和 + 高亮，接近过曝」。所以不要因为「回忆不是彩色像素」就把它全盘否定。

但分层要成立，每一层必须有明确的「进入提示」。日记有纸张边框，回忆有 4:3 星框，这些是好的；标题目前没有「这是现实层」的提示，直接以摄影画面当第一屏，才会让人怀疑「这是不是另一个游戏」。

## 4. 逐项审查

### 4.1 12 张心锁回忆

**做得好的地方**

- 12 张是同一套黑白胶片语言：颗粒、暗角、灰阶一致，放在一起像一组真实老照片，不像随机拼的图。
- 4:3 黑边 + 星点像素框是一个有效的「画框」：它把照片和地图隔开，玩家能理解「这是被翻出来的记忆」。
- `Memory_7` 的处方字、`Memory_12` 的空椅子、`Memory_1` 的井边，叙事指向都清楚。
- 第 12 段静默、空椅子，和「不打开锁」的终章动作对得上，情绪是对的。

**不匹配的地方**

- **摄影 vs 动漫**：皮肤纹理、发丝、布料褶皱都是照片级；游戏头像却是硬边动漫。两者不是「同一部作品的两种画法」，更像「游戏截图 + 电影剧照」。
- **人物身份不连续**：雪儿在游戏里是金发动漫脸；回忆里是黑发真人女性。对照图：[04_角色形象对照.png](批次5_风格审查/04_角色形象对照.png)。如果设定是「幻想中的金发是自我美化」，需要在剧情或 UI 上给出一次明确提示，否则玩家只会觉得「换演员了」。
- **时代与世界观跳脱**：回忆里是当代中国乡村、工厂、医院、公交、酒馆；幻想主线是空中神殿、星空岛、精灵村落。这个反差可以是「现实记忆 vs 幻想防御」，但目前的画面没有给玩家「这是现实」的锚点，只有黑白和画框。
- **HUD 穿帮（已修）**：右上角情绪云在回忆期间已经隐藏，地图菜单按钮也一起隐藏；同时发现情绪云原本被 MZ 菜单按钮完全盖住，已把图标左移 52px。见第 10.2 节与 `运行截图/style_04_memory10_hud_hidden.png`。
- **AI 手部**：Memory_9 的老人手部最明显；Memory_6 持工牌的手指偏长、关节略僵；Memory_2 的手在 640×480 下还能接受。放大看会露馅，正常游玩尺寸下 Memory_9 仍能看出问题。

### 4.2 尾声「醒来」

- **设计上是对的**：GDD 要求现实层「极低饱和 + 高亮，接近过曝」，这张图正好是晨光、白床单、水杯、药瓶、手，和「醒来、吃药、窗外亮」的脚本一致。
- **但它也是摄影**：和回忆是同一套真实层语言，彼此一致；和幻想像素层不一致。
- **作为「现实」可以成立**：如果整个故事的核心是「幻想世界是防御，现实是病房/卧室」，那么尾声用照片级真实画面是有意义的，甚至是必要的。问题不在这一张，而在它之前没有让玩家建立「照片 = 现实」的规则。
- **HUD 已隐藏**：S48 打开后情绪云与地图菜单按钮都会隐藏；尾声照片和制作名单截图右上角已干净。见第 10.2 节。

### 4.3 标题画面

- **优点**：书法标题、雨窗、旧椅子、灰褐调，气质统一，像一部文学向独立游戏的 key art；比原来的 MZ 示例标题好得多。
- **问题 1（已修）：两套命令叠在一起**。现在只保留 `MOG_TitlePictureCom` 的图片命令，默认 `Window_TitleCommand` 移出画面并完全透明，但仍保持输入功能；文案统一为「重新开始 / 继续游戏 / 选项」。修复前后对照见 `运行截图/style_01_title_default.png` 与 `style_02_title_third_selected.png`。
- **问题 2（已修）：命令窗口皮肤和标题冲突**。绿藤 + 紫蓝渐变 + 叶片光标不再绘制；新按钮是暖白衬线 + 小圆点光标，和灰褐摄影标题统一。
- **问题 3：标题不展示游戏**。没有雪儿、没有幻想世界、没有像素元素；第一屏看起来像一部现实题材视觉小说。作为「现实层」的序幕可以，但需要在标题和游戏之间加一次视觉过渡，否则玩家进入像素地图时会觉得换游戏。（**未改**，属于方案 B 的取舍）
- **问题 4（已修）：字体不统一**。菜单改用 SimSun 21px、字距 3 的暖白衬线，选中项下方有细线；不再是默认黑体。

### 4.4 记忆框与 HUD

- 记忆框本身是像素星点，和照片的连续调形成「像素质感的外框 + 照片内容」；这个混合是有效的，建议保留。
- 框外的 HUD 已处理：`MemLock` 播放期间情绪云和地图菜单按钮都会隐藏，只留画框；正常地图上情绪云移到菜单按钮左侧，不再被 48×48 的按钮完全盖住。见第 10.2 节。
- 制作名单期间同样隐藏；截图中已没有 HUD。任务 UI 在当前回忆/名单流程里没有出现，因此未额外改动。

## 6. 建议方案

### 方案 A：保留「照片 = 真实记忆」的分层（改动最小，先做）

适合：你认可「幻想是防御，现实是照片」这个核心表达。

1. 修标题：只保留一套命令；把命令改成细衬线、暖白、无绿藤紫蓝皮肤；或直接重做 `Command_0..2.png`。
2. 回忆、尾声、制作名单期间隐藏情绪云 HUD。
3. 提亮 Memory_10，返工 Memory_9 手部。
4. 在第一次回忆进入时加一个极短的视觉提示（例如画框角上出现「记忆」二字），让玩家知道「照片 = 记忆层」，而不是「贴图错了」。
5. 如果可能，给回忆里的女性一个和雪儿一致的发色/发绳/红杯子等识别物；或者反过来，在游戏里让雪儿看到照片时说一句「那是我吗」。

优点：保留现有 14 张图，成本最低；黑白/过曝的设计意图完整保留。
缺点：摄影与动漫的割裂仍然存在，只是被「画框 + 提示」解释掉。

### 方案 B：统一成「黑白动漫/插画」（推荐，视觉最稳）

适合：你希望玩家觉得「这是一个世界观里的作品」，而不是「游戏 + 电影剧照」。

- 12 张回忆重做成黑白动漫/厚涂插画：保留 4:3、颗粒、暗角、画框；人物用游戏头像的五官和发色做参考；`Memory_7` 仍保留可读的处方字。
- 尾声重做成低饱和/过曝的动漫插画，保留水杯、药瓶、手、晨光。
- 标题改成同源的动漫/厚涂 key art，或至少让标题里的椅子/窗/植物和回忆里的现实场景产生连续。
- 这套方案和游戏已有的「高分辨率动漫头像」是同一语言，不需要把头像改成像素。

优点：整体最统一；既保留现实层的去色，又不会像贴了照片。
缺点：14 张图需要重生成/重绘，成本最高。

### 方案 C：统一成严格像素风

- 回忆改成 320×240 或 480×360 的像素画，限定灰阶色板，最近邻放大；标题/尾声也像素化。

优点：和地图最统一。
缺点：游戏已经有高分辨率动漫头像，像素回忆会和头像打架；处方文字、人物表情在低分辨率下会损失；GDD 要的是「真实记忆」，像素化会削弱真实感。**不推荐作为首选。**

### 我的建议

**先做 A 的 1–3 项（标题、HUD、Memory_10/9），再决定是否走 B。** 因为标题双命令和 HUD 穿帮是明确的执行问题，不管选哪种美术方向都要修；而 14 张图是否重做，应该由「照片=现实」是不是核心表达来决定。

> **2026-10-19 下午进度**：A 的 1–3 已完成（Memory_9 手部返工除外）；方案 B 已生成 1 张同场景对照样图（`06/07/08`），等你决定是否把 14 张全部重做。

## 10. P0 落地记录（2026-10-19 下午）

### 10.1 标题：只保留一套命令，并恢复键盘操作

**根因**：MZ 的 `Window_TitleCommand` 没有 `updatePlacement()`，MOG_TitlePictureCom 里针对该方法的改写永远不会执行，所以默认命令窗口一直叠在图片命令下面。

**处理**：

- 新增 `XueEr_TitlePolish.js`，把默认窗口移到屏幕外（`x = -808, y = -616`），同时设置 `opacity = 0`、`backOpacity = 0`、`contentsOpacity = 0`。
- 关键点：不能把默认窗口设为 `visible = false`。`Window_Selectable.isCursorMovable()` 依赖 `isOpenAndActive()`，而后者要求 `visible === true`；一旦不可见，上下键和确认键全部失效。因此保持 `visible = true`、`active = true`，只做「画外 + 全透明」。
- MOG 图片命令移到左侧留白：`x = 66`，三行 `y = 418 / 456 / 494`（38px 行距）。
- 重新生成 `Command_0..2.png`（168×56，上下两帧各 168×28）与 `Cursor.png`（18×18 圆点）；文案为「重新开始 / 继续游戏 / 选项」，SimSun 21px、字距 3、暖白，选中项下方有细线。
- 插件参数：Menu X 66、Menu Y 418、Line Spacing 38、Cursor X Offset -5、Cursor Y Offset 14。

**实机验证**：`style_01_title_default.png`（单套菜单）与 `style_02_title_third_selected.png`（下键选中「选项」）；下键后 index 1 → 2、上键回到 1，默认窗口保持 `visible=true` 且三个透明度均为 0。

### 10.2 HUD：回忆/尾声/名单隐藏，并修复图标被菜单按钮遮挡

- `XueEr_MoodMeter.js` 增加 `Hidden Switch`（默认 48）：心锁播放中或 S48 打开时，情绪云在 16/帧的步进下淡出并隐藏，结束后恢复。
