## 4. 脚本里踩到的一个坑（下次别再踩）

替换校验最初写成「新串计数差值 == 期望次数」。**当新串是旧串的前缀时这个公式必然误判**：
本例 `你给去那边的`（新）是 `你给去那边的女`（旧）的前缀 → `raw.count(新)` 在替换前后都是 1，差值算出来是 0 → 校验失败、中止。

**正确公式**：
```
① raw2.count(旧串) == 0                       # 旧串必须彻底消失
② len(raw2) - len(raw) == 期望次数 × (新串字节长 − 旧串字节长)   # 字节增量必须精确
```
若两条件都满足，则改动**必然**只发生在目标处。已修正并重跑（第一次的两次落盘已从 b2 备份回滚后重做，最终结果干净）。
