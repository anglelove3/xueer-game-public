## 3. 技术方法（这次踩通的三件事）

### 3.1 地图文件终于能"零噪音"结构化了
之前认定 `Map*.json` 不可重序列化、只能做字节替换。这次把格式试出来了：

```
{\n
<除 data/events 外所有键，紧凑一行>\n
"data":<紧凑数组>,\n
"events":[\n
<每个事件一行，以 ",\n" 分隔>\n
]\n}
```

**实测 32/32 个地图文件 + System.json 逐字节可复现** → 以后改地图事件可以放心用结构化编辑，不用再手抠字节。

### 3.2 定位单位 = "说话人段落"
一页里可能有多个说话人（穆妈/雪儿交替），所以不能按"页"匹配。
`dump_runs.py` 把全工程切成 **257 个说话人段落**（同一说话人下连续的一段 401），修订按段落匹配 + 断言"该页内有且只有一处"，187 处**零误伤**。

### 3.3 折行器（控制码安全）
新文本按 ~20 字自动折行：`\C[4]` / `\V[2]` 这类控制码被视为**原子**，不会被切断；
断行优先落在标点上；最后把 <8 字的碎行合并进上一行（避免出现「！」单独占一行）。
结果：**365 行 401，中位 16 字，最长 29 字，碎行 0**。
